## 🌟 Основні переваги

| Функція | Опис |
| :--- | :--- |
| **🎯 Ідеальні відповідності** | 100% точно вирішує завдання на встановлення логічних пар (1-А, 2-Б, 3-В, 4-Г). |

## 🚀 Швидке встановлення в 1 клік

### Спосіб 1: Напряму в браузер через Tampermonkey (Рекомендовано)

1. Встановіть розширення **Tampermonkey** для вашого браузера:
   - [Tampermonkey для Google Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Tampermonkey для Mozilla Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/)
   - [Tampermonkey для Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
2. Натисніть на посилання нижче — Tampermonkey автоматично перехопить скрипт і запропонує натиснути **«Встановити»**:
   👉 **[⚡ ВСТАНОВИТИ ВСЕОСВІТА AUTO ASSISTANT](https://raw.githubusercontent.com/Ayrannnnn/vseosvita-auto-assistant/main/gemini-quiz-assistant.user.js)**
3. Готово! Скрипт активний і автоматично запускатиметься на всіх тестах Всеосвіти.

---

### Спосіб 2: Офлайн-інсталятор (Windows)

Для знайомих, яким простіше запустити один файл:
1. Завантажте архів із розділу [**Releases**](https://github.com/Ayrannnnn/vseosvita-auto-assistant/releases/latest).
2. Розархівуйте та запустіть **`ЗАПУСТИ МЕНЯ.bat`**.
3. У вікні натисніть зелену кнопку **«2. ⚡ УСТАНОВИТЬ АССИСТЕНТ»** — вкладка встановлення відкриється сама!

## 🔑 Отримання безкоштовного ключа Gemini

Асистент працює напряму з офіційним API Google Gemini. Ключ **безкоштовний назавжди** та видається компанією Google за 30 секунд:

1. Перейдіть на сайт **[Google AI Studio (API Keys)](https://aistudio.google.com/app/apikey)** та увійдіть через свій Google-акаунт.
2. Натисніть синю кнопку **«Create API key»** (Створити ключ API).
3. Скопіюйте отриманий рядок (починається на `AIzaSy...`).
4. Відкрийте будь-який тест на **[Всеосвіті](https://vseosvita.ua/)** — асистент автоматично покаже привітальне вікно, куди потрібно просто вставити ключ і натиснути **«Зберегти»**.
