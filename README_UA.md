## 🚀 Покроковий гайд із встановлення та налаштування

### 1. Встановлення розширення Tampermonkey
Для роботи асистента потрібен браузерний скрипт-менеджер Tampermonkey:
- [Tampermonkey для Google Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Tampermonkey для Mozilla Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/)
- [Tampermonkey для Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)

### 2. Встановлення скрипта в 1 клік
Натисніть на пряме посилання встановлення:
👉 **[⚡ ВСТАНОВИТИ GEMINI QUIZ ASSISTANT v10.7.0](https://raw.githubusercontent.com/Ayrannnnn/vseosvita-auto-assistant/main/gemini-quiz-assistant.user.js)**

Tampermonkey відкриє вкладку перевірки — натисніть **«Встановити»** (або **«Оновити»**, якщо у вас стояла попередня версія).

### 3. Отримання безкоштовного API-ключа Gemini
1. Перейдіть на офіційний портал **[Google AI Studio](https://aistudio.google.com/app/apikey)** та авторизуйтесь під своїм Google-акаунтом.
2. Натисніть синю кнопку **«Create API key»**.
3. На сторінці одразу з'явиться віджет асистента — натисніть **«Прив'язати ключ»** для автозбереження, або просто скопіюйте рядок ключа (починається на `AIzaSy...`).

### 4. Налаштування через Luxe Studio (`⚙`)
Відкрийте будь-який тест на **Всеосвіті** або **На Урок**:
1. У правому верхньому кутку екрана з'явиться напівпрозорий HUD 3.0.
2. Натисніть іконку **`⚙` (Налаштування)**, щоб відкрити **Luxe Studio**.
3. У вкладці **«Моделі & API»** вставте ваш ключ і натисніть кнопку швидкої перевірки.
4. У вкладці **«Стелс & Античит»** активуйте **Стелс-щит** для захисту від відстеження перемикання вкладок.

## ⌨️ Гарячі клавіші

| Комбінація | Дія | Опис |
| :---: | :--- | :--- |
| **`Alt + Q`** / **`Ctrl + Q`** | **Вирішити запитання** | Аналізує поточне завдання, розпізнає графіку та вибирає/вводить правильну відповідь. |
| **`Alt + Shift + Q`** | **Примусовий перепит** | Обходить локальний кеш і надсилає свіжий запит до нейромережі. |
| **`Alt + W`** / **`Ctrl + W`** | **Наступне запитання** | Натискає кнопку підтвердження та переходу («Зберегти і далі»). |
| **`Alt + S`** | **Boss Key (Стелс-перемикач)** | **Миттєво приховує інтерфейс** і перемикає стан Стелс-щита. |
| **`Alt + H`** | **Приховати / Показати HUD** | Плавне приховування або повернення плаваючої панелі на екран. |
| **`Esc`** | **Стоп / Пропуск** | Перериває автопілот або негайно пропускає активну паузу затримки. |

## ❓ Міні-FAQ

<details>
<summary><b>1. Що робити при перевантаженні моделей (помилки 503 або high demand)?</b></summary>

У версії **v10.7.0 Pro Luxe** впроваджено автоматичний каскад:
- При перевантаженні або лімітах скрипт самостійно без вашої участі виконує failover за ланцюжком: `gemini-3.1-flash-lite` → `gemini-3.5-flash-lite` → `gemini-3.8-flash` → `gemini-4-hydrogen`.
- Ви також можете будь-коли відкрити налаштування (`⚙`) → вкладка **«Моделі & API»** і вручну вибрати резервну модель.
</details>

<details>
<summary><b>2. Як очистити кеш відповідей?</b></summary>

- **Спосіб 1:** Натисніть комбінацію клавіш `Alt + Shift + Q` (або іконку `🔄` на панелі), щоб перепитати відповідь на поточне запитання в обхід збереженого кешу.
- **Спосіб 2:** Відкрийте **Luxe Studio** (`⚙`) → перейдіть у вкладку **«Кеш & Бекап»** → натисніть червону кнопку **«Очистити весь кеш»**.
</details>

<details>
<summary><b>3. Як перенести історію відповідей на інший браузер або комп'ютер?</b></summary>

1. На вихідному пристрої відкрийте **Luxe Studio** (`⚙`) → перейдіть у вкладку **«Кеш & Бекап»**.
2. Натисніть **«Експорт у JSON»** — файл з базою збережених відповідей завантажиться на ваш ПК.
3. На новому пристрої відкрийте ту саму вкладку та натисніть **«Імпорт із JSON»**, вибравши збережений файл.
</details>
