Релиз v9.4

✦ Всеосвіта Auto Assistant

Интеллектуальный помощник для тестов на Всеосвіті в 1 клик

1

Запустите файл «ЗАПУСТИ МЕНЯ.bat»

Дважды кликните по файлу ЗАПУСТИ МЕНЯ.bat в этой папке. Откроется компактное окно установщика с автоопределением вашего браузера (Chrome, Firefox или Edge).

💡 Если у вас еще не установлено бесплатное расширение Tampermonkey — нажмите кнопку «1. Установить Tampermonkey» в окне установщика, и откроется официальный магазин расширений.
2

Нажмите «⚡ УСТАНОВИТЬ АССИСТЕНТ»

В окне установщика нажмите большую зеленую кнопку «2. УСТАНОВИТЬ АССИСТЕНТ (1 КЛИК)».

В вашем браузере сразу откроется страница Tampermonkey с кодом ассистента. Просто нажмите кнопку «Установить» (Install).

✨ Всё! Ассистент теперь работает во всех тестах на Всеосвіті автоматически.
3

Бесплатный ключ Gemini API

Чтобы ассистент решал задания через искусственный интеллект Google Gemini:

  1. В окне установщика нажмите «3. Получить бесплатный ключ Gemini» (откроется сайт Google AI Studio).
  2. Нажмите синюю кнопку «Create API key» и скопируйте полученный ключ.
  3. Откройте Всеосвіту — ассистент сам покажет красивое окно, куда останется просто вставить ключ!

Ключ бесплатный навсегда и выдается напрямую компанией Google для личного использования.
