## 🌟 Основные преимущества

| Функция | Описание |
| :--- | :--- |
| **🎯 Идеальные соответствия** | 100% точно решает задания на установление логических пар (1-А, 2-Б, 3-В, 4-Г). |
| **☑️ Множественный выбор** | Безошибочно отмечает несколько правильных вариантов (чекбоксы). |
| **🤖 Режим «Автопилот»** | Сам выбирает правильные варианты ответов и переходит к следующему вопросу. |
| **⏱️ Умная задержка (Smart Delay)** | Рандомизированные паузы (3–8 секунд), имитирующие реальное прочтение человеком для защиты от античита. |
| **🛡️ Мульти-модельный резерв** | Автоматически переключается между моделями Gemini (`3.1 Flash Lite`, `2.5 Flash`, `2.5 Pro`) при исчерпании минутных лимитов. |
| **🔒 100% приватность** | Каждый пользователь использует свой собственный бесплатный ключ. Никаких общих серверов и утечек. |

## 🚀 Быстрая установка в 1 клик

### Способ 1: Напрямую в браузер через Tampermonkey (Рекомендуется)

1. Установите расширение **Tampermonkey** для вашего браузера:
   - [Tampermonkey для Google Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Tampermonkey для Mozilla Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/)
   - [Tampermonkey для Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
2. Нажмите на ссылку ниже — Tampermonkey автоматически перехватит скрипт и предложит нажать **«Установить»**:
   👉 **[⚡ УСТАНОВИТЬ ВСЕОСВІТА AUTO ASSISTANT](https://raw.githubusercontent.com/Ayrannnnn/vseosvita-auto-assistant/main/gemini-quiz-assistant.user.js)**
3. Готово! Скрипт активен и будет автоматически запускаться на всех тестах Всеосвіти.

### Способ 2: Офлайн-установщик (Windows)

Для друзей и знакомых, которым проще запустить один файл:
1. Скачайте архив из раздела [**Releases**](https://github.com/Ayrannnnn/vseosvita-auto-assistant/releases/latest).
2. Распакуйте архив и запустите **`ЗАПУСТИ МЕНЯ.bat`**.
3. В открывшемся удобном окне нажмите зеленую кнопку **«2. ⚡ УСТАНОВИТЬ АССИСТЕНТ»** — вкладка установки откроется сама!

## 🔑 Получение бесплатного ключа Gemini

Ассистент работает напрямую с официальным API Google Gemini. Ключ **бесплатен навсегда** и выдается компанией Google за 30 секунд:

1. Перейдите на сайт **[Google AI Studio (API Keys)](https://aistudio.google.com/app/apikey)** и войдите через свой Google-аккаунт.
2. Нажмите синюю кнопку **«Create API key»** (Создать ключ API).
3. Скопируйте полученную строку (начинается на `AIzaSy...`).
4. Откройте любой тест на **[Всеосвіті](https://vseosvita.ua/)** — ассистент автоматически покажет приветственное окно, куда нужно просто вставить ключ и нажать **«Сохранить»**.

> **💡 Подсказка:** Если при открытии Google AI Studio у вас установлен ассистент, в правом нижнем углу появится плавающий виджет помощника, который позволит привязать ключ в один клик!

## ⌨️ Управление и горячие клавиши

На странице тестирования в правом верхнем углу находится компактная полупрозрачная панель управления:

- **⚡ РЕШИТЬ ВОПРОС:** Мгновенный анализ текущего задания и подсвечивание правильного ответа.
- **🤖 АВТОПИЛОТ (ВКЛ / ВЫКЛ):** Включение непрерывного автоматического прохождения теста.
- **👁 СКРЫТЬ / ПОКАЗАТЬ:** Сворачивание панели в компактную иконку, чтобы не привлекать внимания.
- **⚙️ НАСТРОЙКИ:** Выбор модели Gemini, настройка интервала задержек, смена API ключа.

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Платный ли ключ Gemini API?</b></summary>
Нет, базовый уровень Gemini API абсолютно бесплатен для личного использования (до 15 запросов в минуту и 1500 запросов в день), чего с избытком хватает на сотни тестов.
</details>

<details>
<summary><b>Видит ли учитель или сайт использование ассистента?</b></summary>
Нет. Ассистент работает исключительно на стороне вашего браузера через пользовательский скрипт. Режим «Умной задержки» имитирует естественные движения и паузы человека перед выбором ответа.
</details>

<details>
<summary><b>Что делать, если закончились минутные запросы?</b></summary>
В ассистент встроен механизм автоматического перехода (Failover): если одна модель временно занята, он мгновенно обращается к резервной модели без остановки теста.
</details>
