## 🌟 Основні переваги

| Функція | Опис |
| :--- | :--- |
| **🎯 Ідеальні відповідності** | 100% точно вирішує завдання на встановлення логічних пар (1-А, 2-Б, 3-В, 4-Г). |
| **☑️ Множинний вибір** | Безпомилково відмічає кілька правильних варіантів (чекбокси). |
| **🤖 Режим «Автопілот»** | Сам обирає правильні варіанти відповідей і переходить до наступного питання. |
| **⏱️ Розумна затримка (Smart Delay)** | Рандомізовані паузи (3–8 секунд), що імітують реальне прочитання людиною для захисту від античіта. |
| **🛡️ Мульти-модельний резерв** | Автоматично перемикається між моделями Gemini при вичерпанні хвилинних лімітів. |
| **🔒 100% приватність** | Кожен користувач використовує свій власний безкоштовний ключ. Жодних спільних серверів та витоків. |
