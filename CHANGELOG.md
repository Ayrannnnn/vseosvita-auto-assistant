# 📋 История изменений (Changelog)

Все заметные изменения проекта **Vseosvita Auto Assistant** документируются в этом файле.

---

## [v9.5] - 2026-11-10

### 🛠 Исправления и улучшения
- **Версия в интерфейсе:** исправлено несоответствие версии в HUD (было 9.3, стало 9.5).
- **Повторные попытки при сбоях API:** добавлены ретраи с паузой при ошибках 429/5xx и сетевых таймаутах перед переключением на резервную модель.
- **Безопасность ключа:** ключ Gemini API передаётся через заголовок `x-goog-api-key`, а не через параметр URL.

---

## [v9.5] - 2026-11-10

### ⚡ Добавлено и улучшено
- **Новый 1-Click инсталлер:** добавлено удобное графическое окно на Windows Forms (`ЗАПУСТИ МЕНЯ.bat`) с автоматическим определением установленных браузеров (Chrome, Firefox, Microsoft Edge).
- **Встроенный локальный сервер:** скрипт отдается в Tampermonkey напрямую по клику без ручного копирования кода.
- **Интеграция с Google AI Studio:** добавлен плавающий помощник на `aistudio.google.com` для привязки ключа в один клик.
- **Мастер начальной настройки (Setup Wizard):** при первом входе на Всеосвіту без ключа отображается приветственный диалог с кнопками проверки связи с API и ссылкой на бесплатное получение ключа.

---

## [v9.3] - 2026-11-05

### 🎯 Исправления и доработки
- **Идеальное решение соответствий:** полная переработка алгоритма парсинга логических пар (1-А, 2-Б, 3-В, 4-Г) с учетом динамических идентификаторов Всеосвіти.
- **Множественный выбор:** исправлена обработка вопросов с несколькими правильными ответами (чекбоксы).

---

## [v9.2] - 2026-11-01

### 🤖 Автопилот и безопасность
- **Режим Автопилота:** автоматический клик по верным вариантам и переход к следующему заданию.
- **Умная задержка (Smart Delay):** реалистичная рандомизированная пауза от 3 до 8 секунд между ответами для защиты от алгоритмов античитинга и подозрительной активности.
- **Мульти-модельный резерв (Failover):** поддержка моделей `gemini-2.5-flash-lite`, `gemini-2.5-flash` и `gemini-2.5-pro` с мгновенным автоматическим переключением при превышении квот.

---

## [v9.0] - 2026-10-20

### 🚀 Первый релиз нового поколения
- Прямая работа с Gemini API без сторонних прокси.
- Интуитивная плавающая панель управления прямо в интерфейсе теста.
- Горячие клавиши для быстрого вызова и скрытия интерфейса.
